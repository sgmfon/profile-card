# Profile Card

A responsive, accessible profile card component built with semantic HTML, CSS, and vanilla JavaScript.

## Live Demo
🔗 https://profile-card-peterthiel.vercel.app/

## Features
- ✅ Semantic HTML5 markup
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Accessible keyboard navigation with visible focus states
- ✅ Modern CSS (Flexbox + Grid)
- ✅ Live timestamp display in milliseconds

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/sgmfon/profile-card.git
```

2. Open `index.html` in your browser

That's it! No build process required.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Poppins)
